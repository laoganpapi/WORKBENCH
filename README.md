# workbench

Default home for research, analysis, writing, and repo-less work, run under
the [fabled](https://github.com/laoganpapi/MASTER) behavior system (installed
at project scope — sessions here pick it up automatically).

- `research/`, `analysis/`, `writing/` — one directory per domain; each is
  the base of that domain's storage-escalation ladder (timestamped
  structured files → SQL → graph). Escalation happens only via /retro flags.
- `.claude/CLAUDE.md` — repo facts; `.claude/upstream.md` — patch candidates
  for /promote (tombstoned, never deleted).
