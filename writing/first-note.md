# What this workbench is for

This workbench is the default home for work that doesn't belong to a product
repository: research, analysis, and writing, produced under the fabled system.
Every deliverable runs under exactly one fabled class skill — fabled-research
for source-backed memos and comparisons, fabled-analysis for models and
quantitative computations whose figures will be relied on, fabled-writing for
prose in the owner's voice, and fabled-code for ad-hoc scripts and checks.
Each class arms a gate: work is not done until its checks pass, and every
claim of completion states what was verified and how. Output lives in
timestamped structured files within research/, analysis/, and writing/,
escalating to SQL or graph storage only when a /retro flag justifies it.
Failures become patches before the session ends.
